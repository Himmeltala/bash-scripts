# dvcsx

网页里看 SVN 工作副本或 Git 仓库：变更、差异、提交日志、拉取推送、切换分支、更新提交，以及目录浏览与文件编辑。

## 用法

```
dvcsx                 起网页界面，默认 8100
dvcsx web             同上
dvcsx web --host 127.0.0.1 -p 8771
```

| 选项 | 说明 |
| --- | --- |
| `--host 地址` | 默认 `0.0.0.0`；只想本机用 `127.0.0.1` |
| `-p, --port 端口` | 默认 8100 |
| `-o, --open` | 打开默认浏览器 |
| `--allow-write` | 允许其他机器发起拉取、推送、切换分支、更新与提交；默认只有本机能写 |
| `--json` | 只打一行地址给脚本用 |

页面没有登录，默认绑所有网卡；写操作默认只接受本机请求，加 `--allow-write` 才放开。

## 工作副本

左侧「添加」选一个含 `.svn` 的目录或 Git 仓库目录；先跑 `svn info`，再试 `git rev-parse`，都不是就拒绝。登记只记目录，不动工作副本。Git 可以登记仓库的子目录，只显示该目录下的改动与提交。工作区右键可设别名、复制路径；别名存在 `~/.cache/dvcsx/web/state.json`。

## 变更

列出未提交的改动：修改、新增、删除、重命名、冲突与未跟踪。点一行看差异：SVN 对 BASE、Git 对 HEAD，暂存区的改动也算在内。未跟踪文件显示内容，目录展开成文件，依赖与产物目录不展开，最多 200 条；二进制与非 UTF-8 文件不给看。锁文件（`package-lock.json`、`pnpm-lock.yaml`、`yarn.lock` 等）与构建产物目录（`dist`、`build`、`target` 等）默认不取差异，右侧点「加载差异」才渲染。

页面靠 SSE 自动刷新：服务端每 3 秒查一次状态，变了就推给页面；写操作结束后日志与同步信息也跟着刷新。

## 同步

操作前弹确认，执行中通过 SSE 推送输出；任务在服务端后台跑，关页面不中断，重新打开会接上，也可以取消。

- **Git 切换分支**：本地分支、远端跟踪分支、从当前提交新建；会覆盖未提交改动时拒绝。
- **Git 拉取**：只快进、合并或变基；当前分支必须有上游。
- **Git 推送**：推到上游；没有上游时可设置上游并推送。不提供强制推送。
- **Git 提交**：勾路径、写说明；索引里有未选中的暂存改动时拒绝。
- **SVN 更新**：`svn update`，冲突按 `postpone` 留着。
- **SVN 提交**：冲突、未跟踪、本地缺失的路径先挡住。

同一工作副本同时只跑一个写操作。认证走 credential helper、ssh-agent 或 SVN 已缓存凭据，页面不弹密码；先在终端完成一次登录。

## 提交日志

列出最近的提交：版本号、作者、时间、说明第一行。Git 画出分支时间线，标出待拉取与当前分支领先/落后远端的数量；SVN 显示工作副本版本与待更新版本。选一次提交可看改动路径与差异。Git 默认连远端跟踪分支与标签一起列，可切成只看当前分支；打开或刷新时先同步远端跟踪分支，不动工作区与暂存区。一页 50 条，可加载更多。

## 浏览目录

左侧懒加载目录树，右侧显示文件内容，带行号与语法高亮，读的是磁盘上的文件，未提交改动也能看到。目录不过滤，`.svn`、`.git`、`node_modules`、`dist`、`build`、`target` 等照实列出，搜索也覆盖这些目录；二进制、非 UTF-8 与超过 512KB 的文件不给看。

## 支持范围

判定工作副本、状态、差异、日志、文件读取都按登记类型走 `svn` 或 `git`；浏览目录直接读磁盘。查询只读；写操作只在「同步」页显式触发且默认只认本机。不提供 revert、reset、强制推送。变化检测是每 3 秒轮询，不是文件系统事件。
