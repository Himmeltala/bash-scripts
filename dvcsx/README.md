# dvcsx

网页里看 SVN 工作副本或 Git 仓库：变更、差异、提交日志、拉取推送、切换分支、更新提交，以及目录浏览与文件编辑。

## 用法

```
dvcsx                 起网页界面，默认 8100
dvcsx web             同上
dvcsx web --host 127.0.0.1 -p 8771
```

| 选项 | 说明 |
| --- | --- |
| `--host 地址` | 默认 `0.0.0.0`；只想本机用 `127.0.0.1` |
| `-p, --port 端口` | 默认 8100 |
| `-o, --open` | 打开默认浏览器 |
| `--allow-write` | 允许其他机器发起拉取、推送、切换分支、更新与提交；默认只有本机能写 |
| `--json` | 只打一行地址给脚本用 |

页面没有登录，默认绑所有网卡；写操作默认只接受本机请求，加 `--allow-write` 才放开。

## 工作副本

左侧「添加」选一个含 `.svn` 的目录或 Git 仓库目录；先跑 `svn info`，再试 `git rev-parse`，都不是就拒绝。登记只记目录，不动工作副本。Git 可以登记仓库的子目录，只显示该目录下的改动与提交。工作区右键可设别名、复制路径；别名存在 `~/.cache/dvcsx/web/state.json`。

## 变更

列出未提交的改动：修改、新增、删除、重命名、冲突与未跟踪。Git 分成「已暂存」「更改」「冲突」三组，行内「+」暂存、「−」取消暂存，冲突行的「标记已解决」等于 `git add`。点一行看差异：SVN 对 BASE；Git 按组取，已暂存看索引对 HEAD，更改看工作区对索引，冲突对 HEAD，已暂存组的差异只读。未跟踪文件显示整份内容，目录展开成文件，依赖与产物目录不展开，最多 200 条；二进制与非 UTF-8 文件不给看。锁文件（`package-lock.json`、`pnpm-lock.yaml`、`yarn.lock` 等）与构建产物目录（`dist`、`build`、`target` 等）默认不取差异，右侧点「加载差异」才渲染。

页面靠 SSE 自动刷新：服务端每 3 秒查一次状态，变了就推给页面；写操作结束后日志与同步信息也跟着刷新。

## 同步

操作前弹确认，执行中通过 SSE 推送输出；任务在服务端后台跑，关页面不中断，重新打开会接上，也可以取消。

- **Git 切换分支**：本地分支、远端跟踪分支、从当前提交新建；会覆盖未提交改动时拒绝。
- **Git 拉取**：只快进、合并或变基；当前分支必须有上游。
- **Git 推送**：推到上游；没有上游时可设置上游并推送。不提供强制推送。
- **Git 提交**：先暂存再提交，提交内容就是索引；索引为空时确认后把全部改动暂存再提交；有未解决冲突时拒绝。
- **SVN 更新**：`svn update`，冲突按 `postpone` 留着。
- **SVN 提交**：仍按勾选路径，冲突、未跟踪、本地缺失的路径先挡住；未纳管的文件先在变更页点行尾的加号图标（`svn add`）才能提交。纳入之后又不想提交的，点同一位置的减号图标（`svn revert`）撤回，文件留在工作副本里，回到未纳管。

同一工作副本同时只跑一个写操作。认证走 credential helper、ssh-agent 或 SVN 已缓存凭据，页面不弹密码；先在终端完成一次登录。

## 提交日志

列出最近的提交：版本号、作者、时间、说明第一行。Git 画出分支时间线，标出待拉取与当前分支领先/落后远端的数量；SVN 显示工作副本版本与待更新版本。选一次提交可看改动路径与差异。Git 默认连远端跟踪分支与标签一起列，可切成只看当前分支；打开或刷新时先同步远端跟踪分支，不动工作区与暂存区。一页 50 条，可加载更多。

## 浏览目录

左侧懒加载目录树，右侧显示文件内容，带行号与语法高亮，读的是磁盘上的文件，未提交改动也能看到。打开过的文件各占一个页签，在页签之间切走再切回来，没保存的草稿、选中的视图与滚动位置都还在；切换页签时左侧树自动展开到该文件并滚到它那一行，页签上的圆点表示这份草稿还没保存，关闭这类页签会先问一句。换工作区或切到变更、日志、同步页再回来，那个工作区打开过的页签、没保存的草稿与左侧树展开到哪些目录也接着留着，各工作区互不影响；只活在这次会话里，刷新页面就从头开始。鼠标移进左树时树顶露出一排按钮，「全部收起」一下合上所有展开过的目录。目录不过滤，`.svn`、`.git`、`node_modules`、`dist`、`build`、`target` 等照实列出；搜索默认跳过这些目录（名单在右上角设置里改，见下节），命中的文件按目录归成树，目录可以展开收起。按住 Ctrl（Mac 上 Command）点标识符会问语言服务器要定义：一条直接跳过去，多条列出来选，没装服务器或找不到定义在顶栏说明。右键标识符弹出代码菜单：转到定义、转到类型定义、转到实现、查找引用、重命名符号、复制标识符；引用与多条结果都列在候选框里点着跳。底部状态栏显示光标行列、文件语言与对应的语言服务器状态，点行列可以跳到指定行（Ctrl+G）。打开或保存文件后会取语言服务器推回来的错误与警告：行号前的小圆点、顶栏的问题按钮与列表，点一条跳过去；Shell、Python、JS/TS、Java 走 LSP 推送，Vue 走 tsserver 的同步诊断，都有。Ctrl+P 快速打开工作副本里的文件，Ctrl+Shift+O 打开当前文件的符号大纲，都带筛选框；Ctrl+I 或右键「查看悬停」看光标处标识符的类型、签名与文档，鼠标在标识符上停一会儿也会浮出提示。标签页右键可以关闭、关闭其他、关闭全部、复制相对路径、复制绝对路径（工作区根目录拼上相对路径）。重命名（编辑器里按 F2 也行）先预览要改哪些文件、各改几处，确认后才落盘；改到的文件在页签里开着就重读一遍，有未保存草稿会先让你保存。右键目录可以新建文件或目录，右键文件与目录可以重命名、删除：已纳入版本控制的走 `git mv`/`git rm`、`svn mv`/`svn rm`，保住历史；未纳管的直接动磁盘，新建只落盘不自动纳入，去变更页自行提交。图片（`png`、`jpg`、`jpeg`、`gif`、`webp`、`bmp`、`ico`、`svg`、`avif`）直接预览：默认缩进窗口，点一下按原始大小并可滚动，左下角标尺寸与文件大小；`svg` 还能切回编辑器改源码。其余二进制、非 UTF-8 与超过 512KB 的文件不给看，超过 512KB 的右侧按变更页的过大文件布局显示路径与大小，给一个下载按钮。

## 设置

右上角齿轮打开设置页，改的是全局配置，存在服务端的 `settings.json` 里，所有浏览器共用一份。搜索时跳过的目录名在这里改：一行一个，默认 `.git`、`.svn`、`.hg`、`node_modules`、`__pycache__`、`dist`、`build`、`target`；只按目录名匹配，工作副本里任何一层的同名目录都不往里走，存一份空名单就是不跳过任何目录。

另一页是语言服务器：列出 Shell、Python、JS/TS、Vue、Java 各自的命令与装没装，缺的给出安装命令。代码索引要本机先装好这些命令：`npm i -g bash-language-server`、`npm i -g pyright`、`npm i -g typescript typescript-language-server`；Java 要单独装 Eclipse JDT LS 并把 `jdtls` 放进 PATH：从 `download.eclipse.org/jdtls/snapshots/jdt-language-server-latest.tar.gz` 取快照解压，`bin/jdtls` 是启动器，要求 Java 21 以上（这份 2026-08 的快照实际要 Java 25）。本机装在 `~/.local/share/dvcsx/jdtls`，`~/.local/bin/jdtls` 是按工作目录分 `-data` 的包装脚本，JDK 用 `usr/lib/jvm/java-25-openjdk-amd64`。JS/TS 服务器要带 `tsserver.js` 的 TypeScript 5，全局装成 TypeScript 7 时 dvcsx 会用 `~/.local/share/dvcsx/ts` 里那份。

Vue 单文件组件不另起服务器：dvcsx 用同一份 TypeScript 5 的 tsserver 带上 `@vue/typescript-plugin`，脚本与模板里的定义、引用、重命名都从 tsserver 拿，行列换回 .vue 的真实位置。装它用 `npm i -g @vue/typescript-plugin`；原来那份 `@vue/language-server` 不用也留着。语言服务器按需拉起、空闲 10 分钟停掉，服务退出或移除工作区时一并回收。

## 支持范围

判定工作副本、状态、差异、日志、文件读取都按登记类型走 `svn` 或 `git`；浏览目录的读写与增删改直接动磁盘，删除与改名遇到已纳管的条目才交给 `svn` 或 `git`。查询只读；写操作（同步页的动作、浏览页的保存与增删改）默认只认本机。不提供把改动整份回滚的 revert、reset、强制推送；变更页只撤回刚纳入、还没提交的新增。变化检测是每 3 秒轮询，不是文件系统事件。
