# idex

网页里的轻量级 IDE：浏览与编辑目录，管理 SVN / Git 变更、日志与同步，并可启动 Node、JVM 服务。

## 安装

仓库根目录执行 `./install.sh`。运行时需要 `svn` 或 `git`。Office 预览另装：`./install.sh --deps libreoffice`。

## 用法

```
idex          起网页界面，默认 8100
idex web      同上
```

| 选项 | 说明 |
| --- | --- |
| `--host 地址` | 默认 `0.0.0.0`；只给本机用 `127.0.0.1` |
| `-p, --port 端口` | 默认 8100 |
| `-o, --open` | 打开默认浏览器 |
| `--allow-write` | 允许其他机器发起写操作；默认只有本机能写 |
| `--json` | 只打一行地址给脚本用 |

Git 与 SVN 认证用终端里已缓存的凭据，先在终端登录一次。
